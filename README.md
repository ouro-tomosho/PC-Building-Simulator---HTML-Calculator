# PCBS计算器 使用说明书

《PC Building Simulator》的离线配机计算器：给出预算、目标 3DMark 分数和筛选条件后，**精确**求出最便宜且互相完全兼容的配置；也可以在一台现有主机的基础上，求出最便宜、且能让整机达标的升级方案。

整个应用就是仓库根目录里的 `PCBS-Calculator.html` 一个文件（约 0.88 MB）：双击即可使用，不需要安装、不需要联网、不需要启动服务器，也不会把任何数据传出浏览器。

## 快速开始

1. **打开**：双击根目录的 `PCBS-Calculator.html`，用浏览器打开（Chrome / Edge / Firefox / Safari 均可）。
2. **确认门槛**：侧边栏顶部保持默认的「全部零件已解锁」。要按生涯进度限制零件时，见[设置生涯门槛](#设置生涯门槛)。
3. **选页面**：配一台新机器用「配置生成器」；改造现有主机用「升级生成器」。
4. **填需求**：只需填「预算」和「目标分数」中的**任意一个**，另一个可以留空。
5. **求解**：点「获取配置」或「获取升级方案」。
6. **看结果**：结果表给出该价格档上最便宜的全部方案；点表头可排序，点行尾「复制」可取走纯文本。

> 两个页面共用同一套查询模式，先看懂[三种查询模式](#三种查询模式)就不会填错。

## 界面总览

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 主导航 | 左侧栏 | 在「配置生成器」与「升级生成器」之间切换；当前页面记在网址的 `#` 锚点里 |
| 生涯门槛 | 左侧栏顶部 | 决定哪些零件进入候选池；右侧芯片实时显示候选数量（处理器 / 显卡 / 主板 / 内存 / 机箱） |
| 侧边栏底部 | 左侧栏底部 | 切换主题、重置设置、当前门槛摘要 |
| 查询条件 | 页面主体 | 分组表单；「需求」分组右侧有说明卡，解释当前处于哪种模式 |
| 操作区 | 表单下方 | 「获取…」按钮 + 实时模式提示（随输入变化） |
| 结果区 | 按钮下方 | 汇总指标 + 结果表 |

## 通用操作

### 三种查询模式

由「预算」与「目标分数」是否填写决定，按钮旁的提示会实时告诉你当前处于哪一种：

| 你填了什么 | 会得到什么 |
| --- | --- |
| 只填预算 | 预算以内最便宜的可行方案 |
| 只填目标分数 | 不限预算上限，满足该分数及以上的最便宜方案，即「达到该分数所需的最少预算」 |
| 两个都填 | 预算以内、达到目标分数的最便宜方案 |
| 两个都不填 | 无法求解，按钮旁提示需要至少填写其中之一 |

- **预算留空或填 0 都表示不限预算**，此时「预留预算」一栏自动禁用。
- **预留预算**是留给尚未建模的部件（风扇、存储、电源等）的钱，会从预算中扣除，因此实际可用额度 = 预算 − 预留预算。不需要就填 0。
- 「结果条数」决定同价方案最多列出多少行（默认 15）。它只影响展示条数，不影响求出的最优价格。

### 设置生涯门槛

1. 取消勾选侧边栏顶部的「全部零件已解锁」。
2. 填写**等级**（0–30）。
3. 需要更细的限制时，再填**等级内进度 %**。

规则：等级高于零件的解锁等级即可用；等级相同时再比较等级内进度。等级填 0 相当于不设门槛。改动后候选池立即按新范围刷新，侧边栏底部的摘要也会同步更新。

### 结果表操作

- **排序**：点击任意表头按该列升序排列，再点一次切换为降序。
- **复制**：点行尾的「复制」按钮，把该方案复制成纯文本（配置为 6 行，升级为 3 行），可直接粘贴到聊天窗口或笔记里。
- 浏览器若阻止了剪贴板访问，会提示「浏览器阻止了复制，请手动选中文本复制」。

### 自动保存、主题与重置

- 查询条件、生涯门槛与主题保存在浏览器本地，刷新或重新打开后仍然保留；当前页面也记在网址的 `#` 锚点里，可以直接加书签。
- **切换主题**：深色（默认）与浅色之间切换。
- **重置设置**：清空所有查询条件与生涯门槛，主题保持不变。

## 配置生成器

从零配一台机器：CPU、主板、内存、显卡、机箱**五个槽位全部自由选择**，成本按**整机总价**计算。

### 操作步骤

1. 在「需求」中填**预算**（默认 1500）和/或**目标分数**（默认 6000）。
2. 需要给风扇、存储、电源留钱时填**预留预算**（默认 100），否则填 0。
3. 想多看或少看几个同价方案时改**结果条数**（默认 15）。
4. 可选：在「筛选」「处理器」「主板与内存」「显卡」「机箱」中收窄范围。
5. 点**获取配置**。
6. 在结果表中挑选方案；点表头排序，点「复制」取走文本。

### 条件填写参考

| 分组 | 字段 | 怎么填 |
| --- | --- | --- |
| 需求 | 预算 | 整机可用总价；留空或 0 = 不限 |
| 需求 | 预留预算 | 从预算中扣除的余额；预算不限时本栏失效 |
| 需求 | 目标分数 | 整机 3DMark 分数下限；留空 = 不设分数要求 |
| 需求 | 结果条数 | 同价方案最多列出几行 |
| 筛选 | CPU 与主板均需支持超频 | 勾选后只考虑可超频的 CPU 与主板 |
| 筛选 | 品牌 | 输入厂商名；**软筛选**，某个维度若没有该品牌零件，该维度自动回退为不限 |
| 处理器 | CPU 插槽 | 下拉选择，选项来自当前候选池中实际存在的插槽 |
| 处理器 | CPU 不低于 | 输入型号（自动补全带价格）后，候选为**排名不低于**它的所有 CPU |
| 处理器 | 精确限定为该 CPU | 勾选后只搜索该型号；输入框里不是库中已有型号时本项被禁用 |
| 主板与内存 | 指定主板 | 输入型号则只考虑该主板；留空 = 不限 |
| 主板与内存 | 内存频率不低于 | 下拉选择，选项来自候选内存中实际存在的频率 |
| 主板与内存 | 系统内存不低于 | 整机内存总容量下限（8/16/32/64/128 GB），按「条数 × 单条容量」满足 |
| 显卡 | 显卡数量 | 不限 / 单卡 / 双卡。双卡还需要主板支持对应的 SLI / CrossFire、插槽尺寸足够，机箱也要放得下 |
| 显卡 | 显卡类型 | 不限 / 风冷 / 水冷 |
| 显卡 | 显存不低于 | 下拉选择，选项来自候选显卡中实际存在的显存 |
| 显卡 | 显卡不低于 | 候选为**排名不低于**它的所有显卡 |
| 显卡 | 精确限定为该显卡 | 勾选后只搜索该型号 |
| 机箱 | 指定机箱 | 输入型号则只考虑该机箱；留空 = 不限 |

### 结果表

| 列 | 含义 |
| --- | --- |
| 机箱 / CPU / 主板 / 内存 / 显卡 | 选中的具体型号 |
| 条数 / 卡数 | 内存条数 / 显卡张数 |
| 频率 / 显存 | 内存频率（MHz）/ 显存容量（GB） |
| 功耗 | 整机估算功耗，见[分数与功耗怎么算](#分数与功耗怎么算) |
| 分数 | 整机 3DMark 分数 |
| 价格 | 整机总价 |
| 剩余 | 预算 − 价格；不限预算时显示 `—` |
| 复制 | 复制 6 行纯文本：CPU、主板、内存（条数 + 型号）、显卡（数量 + 型号）、功耗、机箱 |

「内存」列填的是**单条型号**，「条数」是这种内存买几条，因此内存部分的花费 = 单条价格 × 条数。

## 升级生成器

改造现有主机：内存与机箱**沿用原机不更换**，只更换 CPU、主板、显卡，成本按**边际价格**计算，只统计真正换掉的零件。

### 操作步骤

1. 在「需求」中填**升级预算**（默认 1000，留空或 0 = 不限）和/或**目标分数**（默认 8000）。
2. 需要预留时填**预留预算**（默认 0），并可调整**结果条数**。
3. 在「现有主机」里逐项填好当前配置：CPU、主板、内存频率、内存条数、显卡、显卡数量、机箱。**这些字段必须填写，且能在零件库中找到。**
4. 可选：在「替换件的筛选」里限制新零件的品牌、超频能力、显存、类型等。
5. 点**获取升级方案**。
6. 对照汇总栏的「现有主机分数」与「升级后分数」判断是否值得，再决定是否采用。

### 条件填写参考

| 分组 | 字段 | 怎么填 |
| --- | --- | --- |
| 需求 | 升级预算 | 这次改造愿意花的钱；留空或 0 = 不限。只统计实际更换的零件 |
| 需求 | 预留预算 | 从升级预算中扣除 |
| 需求 | 目标分数 | 升级后整机要达到的分数下限 |
| 需求 | 结果条数 | 同价方案最多列出几行 |
| 现有主机 | 当前 CPU / 当前主板 / 当前显卡 / 现有机箱 | 输入型号（自动补全带价格）；必须填写且存在于零件库 |
| 现有主机 | 内存频率 | 下拉选择，只能是零件库中的具体频率 |
| 现有主机 | 内存条数 | 现有内存条数（默认 2） |
| 现有主机 | 显卡数量 | 现有显卡张数（1 或 2） |
| 替换件的筛选 | 更换的 CPU 与主板需支持超频 | 勾选后新换的 CPU 与主板必须可超频 |
| 替换件的筛选 | 品牌 | 软筛选，规则同配置生成器 |
| 替换件的筛选 | CPU 不低于 / 显卡不低于 | 各自带「精确限定」勾选，规则同配置生成器 |
| 替换件的筛选 | 替换后显卡数量 | 不限 / 单卡 / 双卡 |
| 替换件的筛选 | 显卡类型 / 显存不低于 | 不限 / 风冷 / 水冷；显存容量下限 |

### 升级规则要点

- 内存与机箱**永远不会被更换**，因此结果表里不列这两项。
- 现有内存能发挥多少：可用通道数取「内存条数」与「CPU 支持通道数」中的较小值；频率按主板的 XMP 档位向下取到不超过原频率的最大档。
- 边际价格只算真正改变的部分：同型号显卡只是**加装**一张时，只计算多出来的那一张卡的钱。
- 现有零件即使被品牌或超频筛选排除，也仍然可以作为「保留」的选项参与比较，不会被筛掉。
- 型号填错时会明确告诉你缺的是哪一个（例如「未找到该 CPU。」「请填写现有机箱。」）。

### 结果解读

| 汇总指标 | 含义 |
| --- | --- |
| 最便宜升级 / 所需最少预算 | 填了目标分数时显示后者，表示达标所需的最少花费 |
| 升级后分数 | 采用该方案后的整机分数 |
| 现有主机分数 | 当前配置的分数，用来衡量收益 |
| 同价方案 | 该价格档上一共找到几个方案（受结果条数限制） |
| 预算上限 | 你填的升级预算；不限预算时不显示 |

- 结果表中显示 `-` 的格子表示该零件**沿用现有主机**，不产生费用。
- 若现有主机本来就已经达到目标分数，会提示「现有主机已经达到目标分数，下面列出的是仍然最便宜的改动」。
- 「复制」输出 3 行纯文本：CPU、主板、显卡；沿用项写 `-`，显卡只增加张数时会写出张数。

## 结果解读与排错

### 分数与功耗怎么算

- **分数**：先分别算出 CPU 分数与显卡分数，再按 0.85（显卡）/ 0.15（CPU）的权重取调和平均并取整，得到整机 3DMark 分数。
- **功耗**：30 W 基础值 + CPU 功耗 + 显卡数量 × 单卡功耗。
- **价格**：配置生成器是整机总价；升级生成器是边际价格。

### 没有结果怎么办

按顺序尝试：

1. **提高预算**，或者**降低 / 清空目标分数**。
2. **放宽筛选**：把「不低于」改成更低型号、取消「精确限定」、把品牌留空、放宽显存 / 内存频率 / 系统内存下限。
3. **检查双卡要求**：双卡需要主板支持 SLI / CrossFire，插槽尺寸与机箱也要满足；改成「单卡」通常立刻有解。
4. **检查生涯门槛**：等级过低会把候选池压得很小，先勾回「全部零件已解锁」确认是否有解。
5. 以上都试过仍然没有结果，说明在当前零件池与预算下**确实不存在**可行配置，而不是求解失败。

### 其他常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 输入型号后勾选框不可用 | 输入的不是零件库中已有的型号，按自动补全候选填写完整型号 |
| 「获取…」点了没反应 | 「预算」与「目标分数」可能都为空（填 0 也算空），至少填一个 |
| 复制没有生效 | 浏览器阻止了剪贴板，按提示手动选中文本复制 |
| 刷新后设置丢失 | 浏览器在 `file://` 下可能禁用本地存储，此时设置只在本次会话内有效 |
| 换到另一个页面后条件还在吗 | 在。两个页面的条件分别保存，切回原页面即可看到 |

## 重新构建

仓库根目录的 `PCBS-Calculator.html` 是由 `src/`、`web/` 与 `data/catalog.json` 打包生成的。改动源码后重新生成：

```bash
npm run build                                   # 输出到根目录 PCBS-Calculator.html
node tools/build-web.mjs --out 输出文件.html      # 输出到指定路径
```

- 需要 Node.js 16 或更高版本，**没有第三方依赖**，无需 `npm install`。
- 缺少 `data/catalog.json` 时构建会直接报错。
- 重新构建后用浏览器打开新生成的文件即可看到改动。

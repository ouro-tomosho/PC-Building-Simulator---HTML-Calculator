# PCBS计算器

《PC Building Simulator》的离线配机计算器：给出预算、目标 3DMark 分数和筛选条件，**精确**求出最便宜且互相完全兼容的配置；也可以在一台现有主机的基础上，求出最便宜、且能让整机达标的升级方案。

所有计算都在浏览器本地完成 —— 不联网、不需要服务器、不上传任何数据。

## 功能介绍

### 两个生成器

左侧导航在两个页面之间切换，它们回答同一个问题的两种问法：

| 页面 | 解决的问题 | 成本口径 |
| --- | --- | --- |
| **配置生成器** | 从零配一台机器。CPU、主板、内存、显卡、机箱五个槽位全部自由选择 | 整机总价 |
| **升级生成器** | 现有主机做最小改动。内存与机箱沿用原机，只更换 CPU、主板、显卡 | 边际价格，只计算真正被换掉的零件 |

### 三种查询模式

两个页面共用同一套模式，由「预算」和「目标分数」是否填写决定：

| 填了什么 | 输出 |
| --- | --- |
| 只填预算 | 预算以内最便宜的可行方案 |
| 只填目标分数 | 不限预算上限，输出满足该分数及以上的最便宜方案（即「达到该分数所需的最少预算」） |
| 两者都填 | 预算以内、达到目标分数的最便宜方案 |
| 两者都不填 | 按钮旁会提示：请至少填写其中之一 |

- 预算**留空或填 0 都表示不限预算**，此时「预留预算」一栏自动禁用。
- **预留预算**用于尚未建模的部件（风扇、存储、电源等），会从可用预算中扣除，因此实际可用额度为「预算 − 预留预算」。

### 求解结果的保证

- 结果是**精确最优**，不是启发式近似：输出的是该价格档上的全部最优方案，而不是随便一个可行解。
- 汇总栏给出：最优价格（只填分数时为「所需最少预算」）、分数、**同价方案**数量，以及预算上限。
- 结果表列出该最优价格档下的所有同价方案（数量受「结果条数」限制，默认 15）。
- **点击任意表头可按该列升序/降序排序**。

### 结果表怎么读

配置生成器：

- 机箱、CPU、主板、内存（条数与型号）、频率、显卡（卡数与型号）、显存、功耗、分数、价格、剩余。
- **功耗** = 30 W 基础 + CPU 功耗 + 显卡数量 × 单卡功耗。
- **分数**为整机 3DMark 系统分数，由 CPU 分数与显卡分数按 0.85/0.15 加权后取整。
- **剩余** = 预算 − 价格；不限预算时显示 `—`。
- **复制**按钮输出 6 行纯文本：CPU、主板、内存（条数 + 型号）、显卡（数量 + 型号）、功耗、机箱，方便直接贴到别处。

升级生成器：

- 只列真正会变的部件：CPU、主板、卡数、显卡、功耗、分数、价格、剩余。
- **沿用现有主机的零件显示 `-`**，表示未产生费用。
- 汇总栏额外给出「现有主机分数」，方便对比升级前后的收益。
- 若现有主机本来就已经达到目标分数，会明确提示：下面列出的是仍然最便宜的改动。
- **复制**按钮输出 3 行纯文本：CPU、主板、显卡；沿用项同样是 `-`。若显卡只增加了张数，会写出张数。

### 筛选条件

配置生成器的可选项：

- **筛选**：CPU 与主板均需支持超频；品牌。
- **处理器**：CPU 插槽；CPU 不低于（带「精确限定为该 CPU」）。
- **主板与内存**：指定主板；内存频率不低于；系统内存不低于（8/16/32/64/128 GB）。
- **显卡**：显卡数量（不限 / 单卡 / 双卡）；显卡类型（风冷 / 水冷）；显存不低于；显卡不低于（带「精确限定为该显卡」）。
- **机箱**：指定机箱。

升级生成器把筛选分成两组：

- **现有主机**：当前 CPU、当前主板、内存频率、内存条数、当前显卡、显卡数量、现有机箱。
- **替换件的筛选**：更换的 CPU 与主板需支持超频；品牌；CPU 不低于（带精确限定）；替换后显卡数量；显卡类型；显存不低于；显卡不低于（带精确限定）。

几个需要留意的行为：

- 「不低于」按**零件排名**取阈值：所有排名不低于所选型号的零件都进入候选。
- 「精确限定」把候选收窄到该型号本身；输入框里没有库中已有的型号时，勾选框会被禁用并提示原因。
- 品牌是**软筛选**：若某个零件维度上没有任何该品牌的零件，该维度自动回退为不限，避免出现空结果。
- 插槽、内存频率、显存的可选项都来自当前零件池中**实际存在**的取值，不会出现选了却没有零件的选项。
- 双卡不只是数量：主板需要支持对应的 SLI / CrossFire 且插槽尺寸足够，机箱也要放得下。
- 升级时**内存与机箱不参与更换**；实际可用内存通道取「内存条数」与「CPU 支持通道数」的较小值，内存频率按主板的 XMP 档位向下取到不超过原频率的最大档。
- 升级生成器的现有主机各栏必须填写且能在零件库中找到，否则提交时会明确提示是哪一个型号找不到。

### 等级门槛与零件库

侧边栏顶部控制可选零件范围：

- 勾选**全部零件已解锁**（默认）时不做任何限制。
- 取消勾选后可按生涯**等级**（0–30）和**等级内进度 %** 过滤：等级高于零件解锁等级即可用；等级相同时再比较等级内进度。
- 等级填 0 相当于不设门槛。
- 侧边栏底部实时显示当前零件池规模（处理器 / 显卡 / 主板 / 内存 / 机箱各多少个）。

### 其他

- **切换主题**：深色（默认）与浅色之间切换。
- **重置设置**：清空所有查询条件与等级门槛（主题保持不变）。
- **自动保存**：查询条件、等级门槛与主题保存在浏览器本地，刷新或重新打开页面后仍然保留；当前页面也记在网址的 `#` 锚点里，可以直接分享或加书签。
- 结果为空时不会静默失败，而是提示可以尝试的方向（提高预算、降低或清空目标分数、放宽筛选）。

## 如何使用

### 打开

**直接双击 `PCBS-Calculator.html`** 用浏览器打开即可。它是自包含的单文件应用（约 0.88 MB），内嵌了界面、求解核心与零件数据，不需要安装、不需要联网、不需要启动任何服务器。

### 用配置生成器配一台机器

1. 在侧边栏确认等级门槛（默认「全部零件已解锁」），必要时取消勾选并填入等级与进度。
2. 在「需求」里填写条件：
   - 只想在预算内买最便宜的：只填**预算**（默认 1500）。
   - 想知道达到某个分数最少要花多少钱：只填**目标分数**（默认 6000）。
   - 两个都填：得到预算内达标的最便宜方案。
   - **预留预算**默认 100，用于风扇、存储、电源等未建模部件；不需要就填 0。
   - **结果条数**控制同价方案最多列出多少条，默认 15。
3. （可选）在「筛选」「处理器」「主板与内存」「显卡」「机箱」中收窄范围。输入类字段（CPU、显卡、主板、机箱、品牌）支持边输入边检索的自动补全，候选项后面会带价格。
4. 点击**获取配置**。按钮旁的提示会实时说明当前处于三种模式中的哪一种。
5. 在结果表中查看最优价格档的全部方案；点表头排序，点某一行的**复制**取得 6 行纯文本。

### 用升级生成器改造现有主机

1. 在「需求」里填写**升级预算**（默认 1000，留空或 0 表示不限）和/或**目标分数**（默认 8000），以及**预留预算**、**结果条数**。
2. 在「现有主机」里逐项填好当前配置：CPU、主板、内存频率、内存条数、显卡、显卡数量、机箱。这些字段必须能在零件库中找到。
3. （可选）在「替换件的筛选」里限制新零件的品牌、超频能力、显存、类型等。
4. 点击**获取升级方案**。
5. 对照汇总栏中的「现有主机分数」与「升级后分数」判断这次改动是否值得；表格里显示 `-` 的格子表示该零件继续沿用，不花钱。

### 修改源码后重新构建

仓库根目录的 `PCBS-Calculator.html` 是由 `src/`、`web/` 和 `data/catalog.json` 打包生成的。改动源码后重新生成：

```bash
npm run build                                  # 输出到根目录 PCBS-Calculator.html
node tools/build-web.mjs --out 输出文件.html      # 输出到指定路径
```

- 需要 Node.js 16 或更高版本，**没有第三方依赖**，无需 `npm install`。
- 缺少 `data/catalog.json` 时构建会直接报错。
- 重新构建后，用浏览器打开新生成的文件即可看到改动。
